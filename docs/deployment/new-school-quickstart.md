# 새 학교 빠른 시작 안내

다른 학교 선생님이 코드를 몰라도 자기 계정으로 독립된 양치왕을 운영할 수 있도록 하는 절차다. 구글시트 쪽은 메뉴 클릭, 화면 쪽은 버튼 클릭으로 끝난다. 각 학교는 자기 구글시트·Apps Script·Vercel 계정을 쓰므로 학생 데이터가 다른 학교와 섞이지 않는다.

이 문서를 그 선생님께 그대로 전달해도 된다. ①~⑦ 중 ①은 원래 개발자(이 저장소를 가진 사람)가 한 번만 해주면 되고, 나머지는 그 학교 선생님이 혼자 할 수 있다.

## ① (원 개발자가 한 번) Apps Script 코드 준비

```bash
pnpm install
pnpm gas:build
```

`apps-script/dist/Code.js` 내용을 전부 복사해 그 학교 선생님께 전달한다(메신저로 텍스트 파일로 보내도 된다). 이 파일은 코드 수정이 있을 때마다 새로 만들어 다시 전달해야 최신 상태가 유지된다.

## ② 구글시트 새로 만들기

그 학교 선생님이 자기 구글 계정으로 새 스프레드시트를 하나 만든다(이름은 자유, 예: "2026 양치왕").

## ③ Apps Script에 코드 붙여넣기

1. 시트 메뉴에서 **확장 프로그램 > Apps Script**를 연다.
2. 기존에 있던 `Code.js` 내용을 전부 지우고, ①에서 받은 내용을 붙여넣는다.
3. 저장(Ctrl+S)한다.
4. 원래 시트 탭으로 돌아가 **새로고침**한다.

새로고침하면 상단 메뉴에 **🦷 양치왕 설치**가 자동으로 나타난다. 처음 뜰 때 권한 승인 창이 나오면 본인 계정으로 승인한다.

## ④ 설치 마법사 메뉴 클릭

**🦷 양치왕 설치** 메뉴에서 순서대로 누른다.

1. **1단계: 시트 초기화** — 필요한 탭 6개가 자동으로 만들어진다.
2. **2단계: 보안 설정 (비밀번호)** — `/admin` 로그인용 비밀번호를 입력하면 암호화해서 저장한다.
3. **3단계: 스킨 이미지 폴더 만들기** — 전용 Drive 폴더가 자동 생성된다.
4. **4단계: 챌린지 추가** — 챌린지 이름과 목표 일수를 입력하면 첫 챌린지가 추가되고 챌린지 코드가 나온다.

막히면 **설정 상태 확인 / 남은 단계 안내** 메뉴로 지금까지 뭐가 됐는지 확인할 수 있다.

## ⑤ 웹 앱으로 배포

Apps Script 편집기 상단에서 **배포 > 새 배포**를 누른다.

- 유형: **웹 앱**
- 실행 사용자: **나**
- 액세스 권한: **모든 사용자**(익명 포함)

배포를 누르면 `.../exec`로 끝나는 주소가 나온다. 이 주소를 복사해둔다.

## ⑥ 화면(Vercel) 배포

[README의 "Deploy with Vercel" 버튼](../../README.md#다른-학교에-배포하기)을 누른다.

1. Vercel 계정으로 로그인(없으면 무료 가입)한다.
2. 저장소를 그 학교 선생님 계정으로 가져오라고 하면 그대로 진행한다.
3. 환경변수 `NEXT_PUBLIC_APPS_SCRIPT_URL`에 ⑤에서 복사한 `.../exec` 주소를 붙여넣는다.
4. Deploy를 누르면 몇 분 뒤 `https://무언가.vercel.app` 주소가 생긴다.

## ⑦ 확인

1. `https://무언가.vercel.app/?challenge=챌린지코드`로 접속해 학생 참여 화면이 뜨는지 확인한다.
2. `https://무언가.vercel.app/admin`에서 ④-2에서 설정한 비밀번호로 로그인되는지 확인한다.
3. QR 코드는 이 주소를 그대로 QR로 만들면 된다 (관리자 대시보드의 QR 생성 기능을 쓸 수 있다).

실제 iPhone·Android 카메라 허용 점검은 [Phase 1 배포 안내](phase-1.md)의 "4. 출시 전 점검" 항목을 그대로 따른다.
